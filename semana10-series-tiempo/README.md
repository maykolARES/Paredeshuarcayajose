# Semana 10: Series de Tiempo y Redes Recurrentes (RNN, LSTM, GRU)

Aplicación de arquitecturas recurrentes (**SimpleRNN**, **LSTM** y **GRU**) para el pronóstico de series temporales usando dos conjuntos de datos distintos, siguiendo la metodología desarrollada en clase.

## Estructura del Proyecto

- **[`actividad1-clima-univariante/`](./actividad1-clima-univariante)**: Predicción de temperatura diaria (serie temporal univariante) comparando RNN, LSTM y GRU.
- **[`actividad2-energia-multivariante/`](./actividad2-energia-multivariante)**: Predicción de consumo energético (serie temporal multivariante) comparando RNN, LSTM y GRU.

## Tecnologías Utilizadas
- Python 3
- TensorFlow / Keras
- Pandas, NumPy, Scikit-Learn
- Matplotlib, Seaborn
